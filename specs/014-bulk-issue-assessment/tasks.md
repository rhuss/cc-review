**Conventions**: Python 3.9+ stdlib only. Helpers print one JSON line and fail with `Error: <message>` on standard error (exit 1; usage errors exit 2), per `contracts/issue-bulk-cli.md`. Tests use `unittest` with fake `gh` and `git`-adjacent executables placed first on `PATH`, as in `tests/test_issue_assessment.py`; real `git` is used against temporary repositories. The plan's Global Constraints table holds all limits. No em or en dashes in any written text. Fixes never run project code locally (spec FR-024).

## Implementation Strategy

MVP is Phases 1 to 4 (selection plus assessment, approval and posting). Fixes (US3) and the review handoff (US4) add value independently on top; resume (US5) hardens long batches.
