# cc-review documentation

This directory holds everything that documents cc-review.

**Start here:** [GUIDE.md](GUIDE.md) is the entry point to the full cc-review guide.

## What's here

- **[GUIDE.md](GUIDE.md)**: entry point to the guide (overview, usage, how it works, extending, reference).
- **[guide/](guide/)**: the guide source and build tooling, a [cc-guide](https://github.com/rhuss/cc-guide) project. Build or preview it with `cd guide && make preview`.
- **[extras/](extras/)**: supporting material.
  - **[extras/presentation/](extras/presentation/)**: the Slidev talk deck.
  - **[extras/standalone-guide.md](extras/standalone-guide.md)**: standalone quick start for using cc-review without spec-kit.
  - **[extras/reviewer-plugins.md](extras/reviewer-plugins.md)**: the reviewer plugin format reference.
  - **[extras/speckit-guide.md](extras/speckit-guide.md)**: how cc-review integrates with spec-kit and cc-spex.
