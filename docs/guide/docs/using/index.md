This section takes you from a fresh install to a steady review routine. You add cc-review to the coding agent you already run, whether that is Claude Code, Codex, or OpenCode, then put its commands to work on the code and pull requests in front of you. The payoff is a single merged report of the issues worth acting on, rather than a separate result from each reviewer and tool. You also get a clear view of which pull requests, issues, and discussions still need you next. Read the pages in order to get set up and build the routine, or jump straight to the command you need.

The pages, in reading order:

- [Install cc-review](install.md) adds the plugin to Claude Code, Codex, or OpenCode and lists the command-line tools to install first.
- [Review your changes](review.md) runs a review over your current branch or a specific pull request and explains how to read the report it returns.
- [Triage pull request comments](triage.md) sorts a pull request's review comments into bot and human and drafts the replies for your approval.
- [Inbox and issue assessment](inbox-and-issue.md) shows what needs your attention across a repository and helps you judge whether a new issue is worth the work.
