The reference section is where you look up an exact value rather than follow a workflow. It gathers the flag, profile, configuration, and finding-schema details that the task and concept pages mention only in passing. The [Using cc-review](../using/index.md) and [How it works](../how-it-works/index.md) sections explain when and why to reach for these; this section gives the exact values.

The pages:

- [CLI reference](cli.md) lists every flag for the four cc-review commands and what each bundled profile sets.
- [Configuration and finding schema](config-and-schema.md) lists the configuration keys, the order its layers resolve in, and the fields of a finding.
- [Invoking cc-review across harnesses](invocation.md) shows how to call a command on Claude Code, Codex, and OpenCode.
